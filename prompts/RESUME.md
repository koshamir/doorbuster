# RESUME — continue after a break or a context reset

1. Read the STATUS block of `NOTES.md` and the phase prompt it names in `prompts/`.
2. Run `npm run check` and `git status`.
3. Continue the phase from the first unfinished item.
   - Do not redo finished items or repeat a review that has been done.
   - Do not capture shots you have already looked at unless something visual changed since.
